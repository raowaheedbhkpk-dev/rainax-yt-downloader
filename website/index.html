Install in a minute

RAINAX is installed from this page, not from the Play Store, so Android asks you to confirm once.

  1. Download the APK

    Tap Download APK. The file is called RAINAX.apk.

  2. Allow the install

    Open the file. If Android asks, allow your browser or Files app to install apps.

  3. Confirm the warning

    If Play Protect shows "unknown developer", tap More details, then Install anyway.

Get the official app

Questions

Is RAINAX free?

Yes. It is free to download and use.

Why isn't it on the Play Store?

Google doesn't allow YouTube downloaders on the Play Store. That's why you install it from this page and confirm the Play Protect message once.

Do I need to sign in?

No. Signing in to YouTube is optional. It adds your feed, subscriptions, likes, Watch later and commenting.

How do I update?

RAINAX checks for new versions by itself and installs them inside the app. You can also come back here and download the latest APK.

Where are my downloads saved?

In your phone's Downloads folder, in a RAINAX folder. You can choose another folder in Settings.
